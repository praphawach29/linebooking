# Data Retention and Privacy Policy (นโยบายการเก็บรักษาและทำลายข้อมูล)

เอกสารนี้ระบุกรอบนโยบายและระยะเวลาการเก็บรักษาข้อมูล (Data Retention Schedule) ของระบบ SaaS LINE OA Booking เพื่อให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) และมาตรฐานความปลอดภัยสากล

---

## 1. วัตถุประสงค์และขอบเขต

ระบบจะเก็บรวบรวม ใช้ และประมวลผลข้อมูลส่วนบุคคลเท่าที่จำเป็นตามวัตถุประสงค์ในการให้บริการระบบจองคิว จัดการคะแนนสะสม และการชำระเงิน เมื่อพ้นกำหนดระยะเวลาการใช้งาน หรือเมื่อผู้ใช้ใช้สิทธิขอลบข้อมูล ระบบจะดำเนินการทำลายหรือทำให้นิรนาม (Anonymization) ข้อมูลทันที

---

## 2. กำหนดระยะเวลาการเก็บรักษาข้อมูล (Data Retention Schedule)

| ประเภทข้อมูล | ตัวอย่างข้อมูล | ระยะเวลาจัดเก็บ | มาตรการเมื่อครบกำหนด |
| :--- | :--- | :--- | :--- |
| **Audit Logs (ประวัติการใช้งานและปฏิบัติการ)** | รหัสผู้กระทำ, IP Address, การปรับปรุงคะแนน, การเปลี่ยนแปลงสถานะการจอง | **90 วัน** | ทำการลบ (Hard Delete) หรือย้ายเข้าสู่ Cold Archive เพื่อตรวจสอบทางเทคนิค |
| **Payment Slips (ภาพสลิปการโอนเงิน)** | ภาพสลิป PromptPay, ข้อมูลเลขที่อ้างอิงธุรกรรมธนาคาร | **180 วัน** | ลบไฟล์ภาพออกจาก Supabase Storage โดยยังคงรหัสอ้างอิงและยอดเงินในฐานข้อมูลเพื่อตรวจบัญชี |
| **Booking Records (ประวัติการจอง)** | วันที่จอง, บริการ, ช่าง/สนาม, ยอดชำระ | **1 ปี** นับจากวันที่เสร็จสิ้นบริการ | ทำการ Anonymize ข้อมูลติดต่อส่วนบุคคล (ชื่อ/เบอร์โทร) เหลือเฉพาะสถิติรายได้และบริการ |
| **Inactive Customer Profiles** | บัญชีผู้ใช้ที่ไม่มีการจองหรือเข้าสู่ระบบเกิน 2 ปี | **2 ปี** | ทำการ Anonymize ข้อมูลส่วนตัว |
| **Omise Card Tokens / Vault Data** | Token บัตรเครดิต, Omise Customer ID | ตลอดอายุการเป็นสมาชิก | ลบ (Detach) ทันทีเมื่อผู้ใช้กดยกเลิกหรือลบบัตร |

## 3. สิทธิของเจ้าของข้อมูลส่วนบุคคล (PDPA Data Subject Rights - DSR)

ลูกค้าสามารถใช้สิทธิได้ด้วยตนเองผ่านหน้า **LIFF Profile**:
1. **สิทธิในการเข้าถึงและขอรับสำเนาข้อมูล (Right of Access & Data Portability)**:
   - ลูกค้าสามารถกดปุ่ม *"ส่งออกข้อมูลส่วนบุคคล (Export Data)"* เพื่อรับไฟล์ JSON ที่บรรจุข้อมูลโปรไฟล์ ประวัติการจอง และคะแนนสะสม
2. **สิทธิในการขอลบหรือทำลายข้อมูล (Right to Erasure / Anonymization)**:
   - ลูกค้าสามารถกดปุ่ม *"ขอลบข้อมูลส่วนบุคคล (Delete/Anonymize Data)"*
   - ระบบจะแปลงชื่อ-นามสกุล, ลบเบอร์โทรศัพท์, ลบรูปโปรไฟล์, และยกเลิกการผูก LINE User ID ทันที
   - บันทึกยอดเงินทางบัญชีจะถูกเก็บรักษาไว้ตามข้อกำหนดทางกฎหมายการเงินและภาษี

---

## 4. มาตรการรักษาความมั่นคงปลอดภัย (Security Measures)

- ข้อมูลการสื่อสารทั้งหมดถูกเข้ารหัสผ่านโปรโตคอล TLS 1.3
- ข้อมูลบัตรเครดิตจะถูกเก็บในมาตรฐาน PCI-DSS Compliant Vault ของ Omise (Opn Payments) โดยเซิร์ฟเวอร์จะไม่บันทึกหมายเลขบัตร 16 หลักหรือรหัส CVV
- การเข้าถึงข้อมูลระดับ Database มีการควบคุมผ่าน PostgreSQL Row-Level Security (RLS)
