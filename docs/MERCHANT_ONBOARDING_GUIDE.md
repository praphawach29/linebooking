# คู่มือการเริ่มใช้งานสำหรับร้านค้า (Merchant Onboarding Guide)

คู่มือฉบับนี้จัดทำขึ้นสำหรับเจ้าของร้านค้าและผู้ดูแลระบบในการเริ่มต้นใช้งานแพลตฟอร์ม **LINE OA Booking SaaS** ตั้งแต่การสมัครสมาชิก การเลือกโมเดลธุรกิจ การตั้งค่าบริการ และการเปิดรับจองผ่าน LINE

---

## 1. ขั้นตอนการเริ่มต้นใช้งาน (Onboarding Steps)

```
[1. สมัครบัญชีร้านค้า] ➔ [2. เลือกประเภทธุรกิจ] ➔ [3. ตั้งค่าบริการ/ทรัพยากร] ➔ [4. ผูก LINE OA] ➔ [5. เปิดรับจองจริง]
```

### 1.1 สมัครสมาชิกและสร้างร้านค้า (Account & Shop Creation)
1. เข้าสู่ระบบที่ URL: `https://app.linebooking.app/register`
2. กรอกอีเมลและรหัสผ่านเพื่อสร้างบัญชีเจ้าของร้าน (Owner Account)
3. ระบุ **ชื่อร้านค้า (Shop Name)** และ **URL Slug** (เช่น `my-spa` จะได้ลิงก์จอง `https://my-spa.booking.app` หรือเปิดผ่าน LIFF)
4. อัปโหลดโลโก้ร้านและภาพหน้าปก (Cover Image) ขนาดแนะนำ 1200x630 px

---

## 2. การเลือกประเภทธุรกิจ (Business Type Selection)

ระบบรองรับ 3 โมเดลธุรกิจหลัก เลือกร้านค้าของคุณให้สอดคล้องกับการดำเนินงาน:

| ประเภทธุรกิจ | Business Type Key | เหมาะสำหรับ | สิ่งที่ต้องตั้งค่า |
|---|---|---|---|
| **จองสนาม / ทรัพยากร** | `service_court_time` | สนามแบดมินตัน, ฟุตซอล, สตูดิโอห้องซ้อม | คอร์ท/สนาม, ราคาตามช่วงเวลา, ความจุต่อสนาม |
| **จองบริการแบบมีพนักงาน** | `service_staff_time` | ร้านนวด สปา คลินิก ร้านตัดผม | รายชื่อพนักงาน, ความเชี่ยวชาญ, เวลาพัก |
| **จองคลาส / รอบเวลา** | `service_time_only` | คลาสโยคะ พิลาทิส สัมมนา เวิร์กช็อป | รอบเวลา, จำนวนรับสูงสุดต่อรอบ (Capacity) |

## 3. การตั้งค่าบริการและทรัพยากร (Services & Resources)

### 3.1 การสร้างรายการบริการ (Services)
- **ชื่อบริการ**: เช่น *นวดไทยราชสำนัก (90 นาที)* หรือ *เช่าคอร์ทแบดมินตัน (1 ชม.)*
- **ระยะเวลา (Duration)**: กำหนดเป็นนาที เช่น 30, 45, 60, 90, 120 นาที
- **ราคา (Price)**: ราคามาตรฐาน (บาท)
- **ความจุสูงสุด (Max Capacity)**: จำนวนลูกค้าต่อ 1 รอบเวลา (เช่น บริการส่วนตัว = 1, คลาสโยคะ = 12)
- **บริการเสริม (Addons)**: เช่น *เพิ่มการประคบสมุนไพร (+150 บาท)*

### 3.2 การจัดการพนักงาน / ผู้ให้บริการ (Staff Management)
- เพิ่มชื่อ, เบอร์โทร, ความเชี่ยวชาญ และรูปโปรไฟล์
- กำหนดวันและเวลาเข้างาน (Working Days & Shift Hours)
- กำหนดบริการที่พนักงานแต่ละคนสามารถให้บริการได้

### 3.3 การจัดการสนาม / ห้องบริการ (Courts / Rooms)
- เพิ่มรหัสสนาม (เช่น `Court 1 (VIP)`, `Court 2`)
- กำหนดราคาบวกเพิ่มสำหรับห้อง VIP (Extra price per hour)

## 4. การตั้งค่าเวลาเปิด-ปิดและนโยบายการจอง (Booking Policy)

เข้าสู่เมนู **ตั้งค่าร้านค้า (Shop Settings) > นโยบายการจอง**:
1. **เวลาทำการ (Business Hours)**: กำหนดเวลาเปิด-ปิดแยกรายวัน (จันทร์ - อาทิตย์)
2. **ระยะเวลาจองล่วงหน้าขั้นต่ำ (Min Advance Hours)**: เช่น ต้องจองล่วงหน้าอย่างน้อย 2 ชั่วโมง
3. **ระยะเวลาเปิดรับจองล่วงหน้าสูงสุด (Max Advance Days)**: เช่น เปิดรับจองล่วงหน้าไม่เกิน 30 วัน
4. **นโยบายการยืนยัน (Confirmation Mode)**:
   - *Auto-Confirm*: ยืนยันการจองอัตโนมัติเมื่อชำระเงินหรือส่งคำขอ
   - *Manual Confirm*: ร้านค้าต้องกดยืนยันด้วยตนเอง
5. **นโยบายการยกเลิก (Cancellation Policy)**:
   - กำหนดให้ลูกค้ายกเลิกล่วงหน้าได้อย่างน้อยกี่ชั่วโมง (เช่น 6 หรือ 24 ชม.)
   - กำหนดสัดส่วนการคืนเงินมัดจำ (Refund Percentage)

---

## 5. การตั้งค่าระบบชำระเงิน (Payment Settings)

1. **เปิดรับ PromptPay QR**: กรอกหมายเลขพร้อมเพย์ (เบอร์มือถือ 10 หลัก หรือ Tax ID 13 หลัก) และชื่อบัญชีผู้รับ
2. **ระบบตรวจสลิปอัตโนมัติ**: เลือกใช้ SlipOK หรือ EasySlip พร้อมใส่ API Key เพื่อตรวจยอดเงินและเลขอ้างอิงสลิปอัตโนมัติ
3. **การรับบัตรเครดิต (Omise)**: เชื่อมต่อบัญชี Omise เพื่อรับบัตรเครดิต/เดบิตแบบ Real-time

## 6. การทดสอบก่อนเปิดใช้งานจริง (Pre-flight Checklist)

- [ ] ลองเปิดลิงก์ LIFF บนมือถือจริง
- [ ] ทดสอบสร้างการจอง 1 รายการผ่าน LINE OA
- [ ] ตรวจสอบว่าได้รับข้อความ LINE Flex Message ยืนยันการจอง
- [ ] ตรวจสอบรายการจองปรากฏบน **ปฏิทินร้านค้า (Merchant Calendar)**
- [ ] ทดสอบการสแกน QR Code เพื่อเช็กอินลูกค้าหน้าร้าน (Check-in Scanner)
